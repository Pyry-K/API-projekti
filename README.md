# API-projekti -- Character Creator
Tekijät: Pyry Karvinen ja Valtteri Lipponen

# Projektisuunnitelma ja tulevaisuus
"Noppapeleistä kiinnostuneena pojat lähtivät kehittämään hahmon luonti ohjelmaa."
Inspiraatio aiheeseen löytin vähän vahingossa, kun etsimme ilmaisia API järjestelmiä. Erityisesti tässä käytössä oleva D&D 5e SRD API löytyi kun etsimme peleihin liittyviä API mahdollisuuksia.

Suunnitelmat olivat suurempia kuin tämän hetkinen tulos, mutta se antaa selkeän polun jatkokehitykselle.
Lisätietoja tulevista ominaisuuksista saa myöhemmin järjestettävässä esittely / julkaisu seminaarissa.

# Tarkoitus
Sovellus luo hahmon annetuista tiedoista. Syötät nimen, lajin ja luokan. Tämä luo pohjan omatekemälle OC-hahmolle.

# Suunniteltuja (ja tässä versiossa toteutettuja) toimintoja:
1. Nimeä hahmo
2. Laji ja luokka
3. Sunnitelmassa oli tukea useampaa hahmoa ja lisätä tarkempia tietoja hahmosta.

# Tietoja sovelluksesta
Character Creatorin tarkoitus on siis tehdä pohja hahmolle, mitä sitten voi itse jalostaa myöhempää käyttöä varten.
# Teknologiat
Projekti ei ole teknologinen ihme. Käytössä on vain yksinkertaisimmat verkkosivun rakentamiseen vaadittavat kielet.

HTML – sivun rakenne
CSS – ulkoasu ja asettelu
JavaScript – toiminnallisuus, DOM-skriptaus ja lomakkeiden validointi

# Sovelluksen käyttöohjeet

1. Nimeä hahmo.
2. Valitse hahmon laji.
3. Valitse hahmon luokka.
4. Iloitse uudestaa hahmostasi!

# Sovelluksen käynnistäminen paikallisesti

2. Avaa projektikansio.
